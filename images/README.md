# Images

Drop photos here, then reference them in `content.js`.

- `hero.jpg` — the big background photo at the top of the page (landscape, ~2000px wide, under 500 KB).
- `portrait.jpg` — optional portrait shown next to Her Story (4:5 ratio works best).
- Gallery photos — any name; list each one under `gallery` in `content.js`.

Tip: resize/compress with https://squoosh.app before adding so the page stays fast.
